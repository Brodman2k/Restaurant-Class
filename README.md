# Java Lab Challenge

This project practices Java variables, command-line arguments, and output.

## Example Output

```text
Hello! Today is Wednesday, May 4. The current wait time is 4 minutes.
```

## Code

```java
System.out.println("Hello World!");
```

## Topics Covered

- Variables
- Strings
- Integers
- `System.out.print()`
- `System.out.println()`
- Command-line arguments
